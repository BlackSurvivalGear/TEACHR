# TEACHR V1.1

## Implemented

- Teacher profile persisted locally
- Curriculum-aware generation inputs
- Lesson, worksheet and assessment workflows
- Server-side `/api/generate` integration contract
- Provider-compatible AI backend with environment-based secret
- Deterministic frontend fallback for GitHub Pages
- Searchable local resource library
- Duplicate/delete/reload resource actions
- Browser print-to-PDF workflow
- CI validation for frontend and backend JavaScript

## Acceptance criteria

- [x] Existing V1 functionality preserved and extended
- [x] No API key exposed in browser code
- [x] Teacher preferences feed generation prompts
- [x] AI endpoint is server-side
- [x] GitHub Pages remains usable without a backend
- [x] Resources remain local to the browser in this phase
- [x] Print/PDF output available
- [x] CI validates the new backend

## Not yet in V1.1

- Authentication
- Payments
- Student accounts
- Student personal data
- AI marking
- School-wide knowledge bases
- Production hosting for the AI backend
- Rate limiting and production observability
