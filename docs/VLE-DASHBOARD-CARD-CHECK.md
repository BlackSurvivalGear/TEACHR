# VLE member dashboard card verification

1. Sign in to TEACHR with a verified member account.
2. Confirm the authenticated dashboard shows a `TEACHR VLE` card alongside the existing tools.
3. Confirm the card remains visible at desktop, tablet and mobile widths.
4. Select the card and confirm it opens `vle.html`.
5. Confirm the six generating tools and Resource Library still open normally.
6. Confirm opening the VLE does not consume a generation allowance.
