# TEACHR Lesson Builder

## Product goal
Help a teacher go from a teaching idea to a structured, reusable lesson brief with the minimum useful context.

## Current frontend controls
- Subject
- Year / Grade
- Topic
- Duration
- Class profile
- Curriculum
- Question count
- Teacher notes
- Learning objective
- Prior knowledge
- Lesson approach
- Assessment method
- Support / SEND / EAL context
- Resources needed
- Success criteria
- Additional generation instruction

## Behaviour
The lesson-design controls are converted into the existing generation instruction field so the current frontend and future backend share one prompt contract.

## Backend intentionally deferred
No authentication, database, AI provider deployment, payments or server changes are required for this phase.
