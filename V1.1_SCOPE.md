# V1.1 Acceptance Scope

- Teacher profile and preferences persist locally.
- Lesson, worksheet and assessment workflows use richer inputs.
- Browser calls `/api/generate` instead of exposing a provider key.
- Backend can proxy an OpenAI-compatible provider using environment secrets.
- Frontend falls back to deterministic demo output when backend is unavailable.
- Resource library supports search, duplicate, delete and reload.
- Generated resources can be printed to PDF via the browser.
- CI validates frontend and backend JavaScript.
