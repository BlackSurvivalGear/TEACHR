# Stage 3 acceptance criteria

- Existing members retain the exact sum of unused allowance across all six generation tools.
- Historical admin grants are preserved.
- New/no-usage members resolve to 18 Credits.
- Migration is idempotent and cannot double-award Credits.
- Legacy usage records remain untouched for rollback/audit.
- Pro/Admin/Superadmin stored Credit balances are preserved.
- No production generator is switched to Credits in Stage 3.
